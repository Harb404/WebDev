MASALIHIT LUXE — FRONT PAGE GUIDE
==================================

FILES
-----
index.php   -> the page content (HTML). No PHP logic is used yet, it's just
               plain HTML saved as .php so it will run on any PHP server.
style.css   -> all the visual styling (colors, fonts, spacing, layout).
               Linked from index.php via:
               <link rel="stylesheet" href="style.css">

Keep both files in the SAME folder. If style.css is missing or moved,
the page will load with no styling (plain black text on white).


HOW THE PAGE IS ORGANIZED (top to bottom)
------------------------------------------
1. <header>            Sticky top navigation bar (logo, menu links, search box)
2. <section class="hero">        Big intro banner: "BUILD FOR THOSE WHO MOVE FIRST"
3. <section class="about">       The brand story paragraph + two image boxes
4. <section id="features">       "Featured Collection" — the 4 product cards
                                   (Tumbler, Air1 shoe, Cap, Shirt)
5. <section class="testimonials"> Customer review cards ("Style Your Ideal")
6. <section class="fuel">        "Fuel Your Potential" spec/description panel
7. <section class="banner">      "Peak Performance. Zero Excuses" call-to-action
8. <footer>             Bottom links (Company / Collection / Support) + copyright


WHERE TO EDIT TEXT
-------------------
Just open index.php in any text editor and change the words directly.
Examples:
  - Headline:        search for  "Build for"
  - Tagline:         search for  "Footwear, shirts, tumblers"
  - Product names/prices: search for  "M-Luxe Tumbler", "M-Luxe Air1", etc.
  - Reviews:          search for  "Richard Cornelius Timosa"
  - Footer text:      search for  "Next-generation design"

Nothing else needs to change — just edit the words between the tags,
don't delete the < > tags themselves.


WHERE TO ADD YOUR OWN PHOTOS
------------------------------
Right now the shoe/product graphics are simple line drawings (SVG code)
used as placeholders. To swap in a real photo:

1. Put your image file in the same folder (e.g. make an "images" folder
   and put shoe-air1.jpg inside it).

2. In index.php, find the placeholder block you want to replace.
   Each one starts with either:
      <svg class="shoe-svg">          (hero image)
      <svg viewBox="0 0 420 340">     (about section images)
      <svg viewBox="0 0 100 100">     (the 4 product thumbnails)
      <svg viewBox="0 0 300 380">     (fuel/spec panel image)

3. Delete that whole <svg> ... </svg> block and replace it with:
      <img src="images/shoe-air1.jpg" alt="M-Luxe Shoe Air1"
           style="width:100%; height:100%; object-fit:cover;">

   (object-fit:cover keeps the photo filling the box neatly without
   stretching it.)

There are 8 placeholder graphics total:
  - 1 in the hero section
  - 2 in the about section
  - 4 in the featured collection (tumbler, shoe, cap, shirt)
  - 1 in the fuel/spec section


WHERE TO EDIT COLORS / FONTS (style.css)
-------------------------------------------
At the very top of style.css there's a block like this:

  :root{
    --ink:#0d0d0e;      <- main background (near-black)
    --panel:#151517;    <- card background
    --bone:#f3efe6;     <- main text color (off-white)
    --gold:#d3a24a;     <- gold accent color (prices, highlights, buttons)
    --track:#b5442e;    <- rust/red accent used sparingly
  }

Changing any of these hex codes updates that color EVERYWHERE on the
page automatically, since every section reuses these same variables.
This is the easiest way to reskin the whole site's color scheme.


NOTES ON THE "BUTTONS"
-------------------------
There are no <button> elements on this page — every clickable action
(Shop the Drop, Our Story, View Collection, nav links, footer links)
is a plain link (<a> tag) styled to look like a button. This was done
on request. If you ever want real <button> elements instead (for
example to hook up JavaScript actions), let me know and I can convert
them.
